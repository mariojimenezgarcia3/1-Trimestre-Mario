Programación Cableada: Circuito Combinacional

Análisis, diseño con puertas lógicas (NOT, AND, OR), ecuación booleana, tabla de verdad completa y simulación interactiva del circuito cableado de 3 entradas (a, b, c).

Esquema Cableado Implementado (Simulador)

Montaje en simulador lógico con 3 pulsadores de entrada (a, b, c), dos inversores (NOT), dos puertas multiplicadoras (AND), una puerta sumadora (OR) y una sonda LED de salida.

Análisis Booleano y Simplificación

1. Rama Superior (Puerta AND 1): Recibe la entrada a invertida (a') y la entrada c invertida (c'). Produce el término: a' · c'.
2. Rama Inferior (Puerta AND 2): Recibe directamente las señales a y c sin negar. Produce el término: a · c.
3. Puerta OR Final y Función Resultante: Suma ambas ramas, generando una función XNOR (Coincidencia) entre a y c (la entrada b queda desconectada / es indiferente):
S(a, b, c) = (a' · c') + (a · c) = a ⊙ c

Sistema Biestable (Set / Reset) con Arduino UNO y C++

Montaje electrónico con placa Arduino UNO, protoboard, dos pulsadores con resistencias pull-down y dos diodos LED (verde y amarillo) gobernados mediante código C++.

Circuito Electrónico en Protoboard (Tinkercad)

Pin Digital 2 boton (Set)
Pin Digital 3 v (LED Verde)
Pin Digital 4 a (LED Amarillo)
Pin Digital 5 boton2 (Reset)

Código Fuente en C++ (Arduino) 

const int boton = 2;
const int v = 3;
const int a = 4;
const int boton2 = 5;

void setup() {
  pinMode(boton, INPUT);
  pinMode(v, OUTPUT);
  pinMode(a, OUTPUT);
  pinMode(boton2, INPUT); // En captura: OUTPUT
}

void loop() {
  if (digitalRead(boton) == 1) {
    digitalWrite(v, HIGH);
    digitalWrite(a, HIGH);
  }
  if (digitalRead(boton2) == 1) {
    digitalWrite(v, LOW);
    digitalWrite(a, LOW);
  }
}
Funcionamiento Lógico: Actúa como un biestable Set-Reset (enclavamiento). Al pulsar boton (pin 2), ambos LEDs se encienden y permanecen encendidos aunque se suelte el botón, hasta que se pulsa boton2 (pin 5) para apagarlos.

not (Negación)

Invierte el valor booleano: not (x > y) es verdadero si x <= y.
